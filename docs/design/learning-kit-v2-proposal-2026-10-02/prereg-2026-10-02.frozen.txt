## 1. 協議（`agreed-v2`）

| 項目 | 內容 |
|---|---|
| 紙 | 單頁 A4，左右手共用，四個 ArUco 標記、腕線、中線、參與者卡槽（`P###` QR） |
| 拍攝者 | Kirby 一人 |
| 每人時間 | ≤ 30 秒（不含同意與資料登錄） |
| 手 | 只拍他用滑鼠的那隻手 |
| 姿勢與張數 | G02 平放張開 ×3，G04 爪握 ×2；每張重新擺手。S0 實測後若超時，改為 G02 ×2、G04 ×2 |
| 多拍 | 僅當手明顯不在紙上或紙角被遮住，多拍 1 張並記錄一次；不因產品拒絕而重拍 |
| 同意與資訊 | 同意書由 Kirby 另外簽；用滑鼠的手、自述握法（掌／爪／指尖／不確定）、年齡區間（選填）併入同意流程，以 `P###` 對應 |
| Session 紀錄 | 每個 session 一次：日期、時段、場地、光源、手機型號與鏡頭、持機方式；開始時量印出紙上的 100 mm 線 |
| 協議命名 | `agreed-v2`；`candidate-v1` 的值不與之混用 |
| 真值 | **無。** 無尺量真值；參考值為同一張紙上標記平面量到的毫米 |

## 2. 判準

| 項目 | 判準 | 狀態 |
|---|---|---|
| 重複性（G02 手長） | 組內 SD 的合併值 ≤ 1.0 mm（以每位參與者 3 張計） | **啟用** |
| 路徑一致度 | 紙邊緣路徑與標記路徑的差：偏差、SD，以人為單位 | 只報告 |
| 曲度比 | 爪握的腕到中指尖投影長 ÷ 同人 G02 手長；報告重拍變異 | 只報告 |
| 產品閘門接受率 | 各姿勢 accepted ÷ 全部 | 只報告 |
| 涵蓋度 | 手長分佈、手機、光線、左右手 | 只報告 |
| 準確度（對尺 MAE ≤ 2.0 mm，人為單位） | — | **休眠：無真值，有真值時才啟動** |

SD ≤ 1.0 mm 是從 PLAN 的「±1.5 mm / 5 張」推出的對應值，不是文獻。

**可宣稱與不可宣稱：** 只可寫「與標記紙參考值的一致度」「重拍重複性」。**不可寫**「準確到 x mm」「對真手準確」。

## 3. held-out 規則（寫死）

- **亂數種子：** `bec9449f79d85ac5`（2026-10-02 由作業系統的密碼學亂數產生）。
- **規則：** 參與者編號 `P###` 每 4 人一組（P001–P004、P005–P008……）。每組內，以 SHA-256 對字串 `<種子>:<P###>`（UTF-8，例如 `bec9449f79d85ac5:P004`）取十六進位小寫字串，**字串最小者**為該組的 held-out，其餘三人為調校用。
- 因此 held-out 恰為 25%，且收集中途停止仍成立（只對湊滿 4 人的組有效）。
- **S0 編號 P901–P912：不進調校、不進 held-out。**
- **held-out 評估：** Claude 在主迴圈只跑一次，凍結模型後執行；不在 workflow 內；看過結果後不重跑。

## 4. S0 的判準（建議，S0 後可依結果修訂，但須新版本）

| 問題 | 判準 | 不過的話 |
|---|---|---|
| 5 張在 30 秒內？ | 90% 的人 ≤ 30 秒 | 改為 G02 ×2、G04 ×2 |
| 每張照片認得出誰與哪個姿勢？ | 100% | 改卡槽或順序規則 |
| 爪握與張開的手別標籤與同意流程所記一致？ | ≥ 90% | 這兩個姿勢的手別警告視為噪音 |
| 重複性達標？ | 合併 SD ≤ 1.0 mm | 找原因後改 |
| 爪握照能偵測到手？ | 只報告偵測率 | 若很低，改拍法 |

## 5. 隱私與同意

- 同意書由 Kirby 另外簽，措辭不在本檔。
- **要點：**
  - 蒐集：手部照片（含 EXIF）、同意流程所記欄位。
  - **明寫照片可能被第三方 AI 服務處理**（Kirby 決定）。
  - 只用 `P###`，不留姓名。
  - 撤回與刪除時限待 U1，不沿用產品文案。
  - 不做醫療宣稱。
- 送雲端前先剝除 EXIF（GPS、時間、裝置序號）。
- 照片與紀錄存放於 repo 外。

## 6. 已知並接受的限制

- 無法對真手證明準確度。
- 標記平面對真手若有偏差，ML 會學進去，無法偵測。
- 兩條路徑共用地標偵測，路徑一致不代表地標準。
- 單人拍攝比真實自拍穩定；以不同 session 換地點、光線、手機（至少兩支）、手持不用腳架緩解。
- 30 秒與 5 張為估計，S0 實測。
