# Security policy

## Reporting a vulnerability

Please report security problems **privately**, through GitHub's private
vulnerability reporting. Do not open a public issue, pull request or discussion
for a vulnerability.

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**
   (direct link: <https://github.com/kirbyliu99M/Open_Mouse/security/advisories/new>).
3. Describe the problem: what you found, where, the steps to reproduce it, and
   the impact you think it has.

This is the only reporting channel. No email address is published for security
reports.

This is a volunteer-run project. We read every report but do not promise a
response time.

## What counts

The web app deployed from `main`, and the code in this repository. Reports that
show the app breaking one of its own privacy promises are in scope:

- a photo leaving the browser (only derived millimetre values may be sent), or
- an anonymous scan still readable after its 24-hour expiry.

Only the latest commit on `main` is supported. There are no maintained older
versions.

## 回報資安問題（繁體中文）

請使用 GitHub 的私密漏洞回報（private vulnerability reporting）通報，
**不要**在公開的 issue、pull request 或 discussion 裡貼漏洞細節。

1. 進入本 repository 的 **Security** 分頁。
2. 點 **Report a vulnerability**
   （直接連結：<https://github.com/kirbyliu99M/Open_Mouse/security/advisories/new>）。
3. 寫明發現了什麼、在哪裡、重現步驟，以及你判斷的影響。

這是唯一的回報管道，本專案不公布任何 Email 收資安通報。本專案由志工維護，
我們會閱讀每一份回報，但不承諾回覆時限。
